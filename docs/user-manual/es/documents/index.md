# Documentos

Genera documentos dentales con marca de agua — recetas, certificados
médicos, cartas de derivación y solicitudes de radiología — desde la
ficha del paciente o directamente desde la barra lateral. Los documentos
se almacenan junto al registro del paciente y se pueden regenerar o
archivar.

## Pantallas

- [Lista de documentos](./screens/documents.md): búsqueda, filtros
  por tipo/estado, alta, edición, generación de PDF, archivo.
