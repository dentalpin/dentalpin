## DentalPin ఎందుకు?

ప్రపంచవ్యాప్తంగా దంత క్లినిక్‌లకు ఒకే రకమైన ప్రాథమిక అవసరాలు ఉన్నాయి: రోగులను నిర్వహించడం, అపాయింట్‌మెంట్లు షెడ్యూల్ చేయడం, చికిత్సలను గమనించడం మరియు ప్రాక్టీస్‌ను సమర్థవంతంగా నడపడం. అయినా సాఫ్ట్‌వేర్ రంగం డజన్ల కొద్దీ ప్రాంతీయ, క్లోజ్డ్-సోర్స్ పరిష్కారాలుగా విడిపోయి ఉంది — అవి క్లినిక్‌లను ఖరీదైన ఒప్పందాలు మరియు పాతబడిన సాంకేతికతలో బంధిస్తాయి.

**మార్పుకు సమయం వచ్చిందని మేము నమ్ముతున్నాము.**

DentalPin ఒక సరళమైన ఆలోచనపై నిర్మించబడింది: **ప్రతిచోటా దంత క్లినిక్‌ల కోసం ఒకే ఓపెన్ ప్లాట్‌ఫారమ్**. మరో ప్రాంతీయ పరిష్కారం కాదు — ఏ క్లినిక్ అయినా స్వీకరించగల, ఏ డెవలపర్ అయినా విస్తరించగల, ఏ సమాజమైనా స్థానికీకరించగల ప్రపంచ పునాది.

### ఇప్పుడే ఎందుకు?

చిన్న బృందాలు ఏమి నిర్మించగలవో AI ప్రాథమికంగా మార్చేసింది. ఒకప్పుడు పెద్ద డెవలప్‌మెంట్ విభాగాలు అవసరమైన ఫీచర్లను ఇప్పుడు రోజుల్లో అమలు చేయవచ్చు. క్లినిక్‌లు బయటపడలేని పాత వ్యవస్థల్లో చిక్కుకోక ముందే — సంవత్సరాల క్రితమే ఉండాల్సిన సోర్స్-అందుబాటు దంత సాఫ్ట్‌వేర్‌ను (BSL 1.1, ప్రచురణ తర్వాత నాలుగు సంవత్సరాలకు Apache 2.0 గా మారుతుంది) సృష్టించడానికి ఇదే మా అవకాశం.

### మా సూత్రాలు

- **సోర్స్-అందుబాటు (BSL 1.1)** — మీ క్లినిక్ డేటా మీదే. మీ సాఫ్ట్‌వేర్ కూడా అలాగే ఉండాలి.
- **మాడ్యులర్** — సరళంగా ప్రారంభించండి, అవసరమైనది జోడించండి. ఎప్పుడూ వాడని ఫీచర్లకు చెల్లించకండి.
- **ప్రపంచవ్యాప్తంగా రూపొందించబడింది** — మొదటి రోజు నుండే స్థానికీకరణ కోసం నిర్మించబడింది. ఒకే కోర్, ఏ భాష అయినా, ఏ దేశమైనా.
- **API-ప్రధానం** — ప్రతి ఫీచర్ ఒక API. దేనితోనైనా అనుసంధానించండి, అన్నింటినీ ఆటోమేట్ చేయండి.
- **AI-సిద్ధం** — AI యుగం కోసం నిర్మాణం. తెలివైన షెడ్యూలింగ్, క్లినికల్ నిర్ణయ సహాయం మరియు పని ప్రక్రియల ఆటోమేషన్‌కు సిద్ధంగా ఉంది.

### మా దృష్టి

మేము కేవలం సాఫ్ట్‌వేర్‌ను మాత్రమే నిర్మించడం లేదు — ఒక పర్యావరణ వ్యవస్థకు పునాది వేస్తున్నాము. డెవలపర్లు మాడ్యూల్‌లను అందించే, క్లినిక్‌లు మెరుగుదలలను పంచుకునే, మొత్తం దంత సమాజం సమిష్టి ఆవిష్కరణ నుండి ప్రయోజనం పొందే ప్లాట్‌ఫారమ్.

గత దశాబ్దపు క్లోజ్డ్, ఖరీదైన సాఫ్ట్‌వేర్ కంటే మెరుగైనది క్లినిక్‌లకు దక్కాలి. DentalPin ఓపెన్ ప్రత్యామ్నాయం.

## ✨ AI కోపైలట్

DentalPin లో అంతర్నిర్మిత **ఏజెంటిక్ AI సహాయకుడు** ఉంది — దీనితో మొత్తం క్లినిక్‌తో మీరు నేరుగా మాట్లాడవచ్చు. రోగిని కనుగొనమని, ఒక సమయాన్ని ఖాళీ చేయమని, సమాధానం రాని అంచనాను ఫాలో-అప్ చేయమని, లేదా ఈరోజు ఏముందో చెప్పమని సాధారణ భాషలో అడగండి — అది మీ నిజమైన డేటాపై పని చేస్తుంది.

![AI కోపైలట్](docs/screenshots/ia.png)

ఇది పైన అతికించిన చాట్‌బాట్ కాదు. కోపైలట్ నిజమైన ఏజెంట్ — UI చేసే అవే ఆపరేషన్లను పిలిచి, రోగులు, షెడ్యూల్, రీకాల్స్, అంచనాలు, చెల్లింపులు మరియు నివేదికలలో **అనేక దశల పనులను ప్రణాళిక చేసి అమలు చేస్తుంది**.

- **సమాధానం మాత్రమే కాదు, పని చేస్తుంది.** ఏజెంట్ నిజమైన టూల్స్‌ను నడుపుతుంది — రోగులను వెతకడం, అపాయింట్‌మెంట్లు బుక్ చేయడం లేదా మార్చడం, చెల్లింపు నమోదు చేయడం, ఈ నెల వసూళ్లను తీసుకురావడం — మరియు పనిని పూర్తి చేయడానికి వాటిని గొలుసుగా కలుపుతుంది.
- **మీ పాత్ర పరిధిని ఎప్పుడూ దాటదు.** ప్రతి టూల్ కాల్ అమలు సమయంలో పిలిచిన యూజర్ RBAC అనుమతులతో మళ్ళీ తనిఖీ చేయబడుతుంది. ఆ యూజర్ UI ద్వారా చేయగలిగినది *ఖచ్చితంగా* అంతే కోపైలట్ చూడగలదు, చేయగలదు — అంతకు మించి కాదు, వారి క్లినిక్‌కు పరిమితం.
- **మీ డేటా సురక్షితంగా ఉంటుంది.** LLM ప్రొవైడర్‌కు ఏదైనా వెళ్ళే ముందు ఆరోగ్య సమాచారం (PHI) దాచబడుతుంది: రోగి పేర్లు, ఫోన్లు, ఈమెయిల్‌లు మరియు IDలు స్థిరమైన టోకెన్లతో మార్చబడతాయి, ఉచిత-పాఠ్య క్లినికల్ టూల్స్ క్లౌడ్ మార్గం నుండి పూర్తిగా మినహాయించబడతాయి. రిడాక్షన్ డిఫాల్ట్‌గా ఆన్‌లో ఉంటుంది.
- **మార్పులకు ముందు అడుగుతుంది.** డేటాను మార్చే ఏ చర్య అయినా (బుకింగ్, చెల్లింపులు, సవరణలు) అమలు చేసే ముందు సంభాషణ మధ్యలో ఆగి మీ స్పష్టమైన నిర్ధారణ కోసం వేచి ఉంటుంది.
- **మార్గదర్శక పని ప్రక్రియలు.** సిద్ధంగా ఉన్న ప్లేబుక్‌లు — *రోజువారీ సారాంశం*, *సందర్శనకు సిద్ధం చేయండి*, *ఖాళీని భర్తీ చేయండి*, *గడువు వచ్చిన రీకాల్స్*, *సమాధానం లేని అంచనాలు* — సాధారణ అనేక-దశల పనులను ఒక్క నొక్కుతో ప్రారంభిస్తాయి.
- **ముందస్తు సారాంశాలు.** ఈరోజు షెడ్యూల్, గడువు వచ్చిన రీకాల్స్ మరియు తెరిచి ఉన్న అంచనాలను సంక్షిప్తంగా చెప్పే ఉదయపు ఈమెయిల్ సారాంశాన్ని మీ బృందానికి పంపేలా ఎంచుకోవచ్చు — LLM లేదు, ఆరోగ్య సమాచారం బయటకు వెళ్ళదు.
- **మాడ్యులర్ రూపకల్పన.** కోపైలట్ ప్రతి మాడ్యూల్ ఒక భాగస్వామ్య రిజిస్ట్రీ ద్వారా ప్రచురించే టూల్స్‌ను వాడుతుంది; ప్రతి మాడ్యూల్ దాని స్వంత సామర్థ్యాలను అందిస్తుంది, కాబట్టి కొత్త మాడ్యూల్‌లు ఇన్‌స్టాల్ అయినప్పుడు ఏజెంట్ స్వయంచాలకంగా పెరుగుతుంది.

అంతర్గతంగా ఏ వెండర్‌కూ కట్టుబడి లేదు (LLM-ప్రొవైడర్ అబ్‌స్ట్రాక్షన్); ప్రొవైడర్, మోడల్ మరియు క్లినిక్ వారీ టోకెన్ బడ్జెట్‌లను ప్రతి డిప్లాయ్‌మెంట్‌కు కాన్ఫిగర్ చేయవచ్చు. ఆర్కిటెక్చర్: [docs/technical/copilot-agentic-architecture.md](docs/technical/copilot-agentic-architecture.md).

## ఇన్‌స్టాలేషన్

ముందే నిర్మించిన ఇమేజ్‌లు — క్లోన్ అవసరం లేదు, బిల్డ్ అవసరం లేదు. Docker ఉన్న ఏ సర్వర్‌లోనైనా:

```bash
curl -O https://raw.githubusercontent.com/dentalpin/dentalpin/main/docker-compose.prod.yml
curl -O https://raw.githubusercontent.com/dentalpin/dentalpin/main/Caddyfile
curl -o .env https://raw.githubusercontent.com/dentalpin/dentalpin/main/.env.prod.example

# .env లో PUBLIC_URL, POSTGRES_PASSWORD మరియు SECRET_KEY సెట్ చేసి, తర్వాత:
# BUDGET_PUBLIC_SECRET_KEY: openssl rand -hex 32
# AGENDA_PUBLIC_SECRET_KEY: openssl rand -hex 32
docker compose -f docker-compose.prod.yml up -d
```

సర్వర్‌కు ఒక డొమైన్‌ను సూచించి, `PUBLIC_URL=https://your-domain` సెట్ చేయండి — మొదటి బూట్‌లోనే TLS
అందుబాటులోకి వస్తుంది. Caddy రెండు సేవలనూ ఒకే ఆరిజిన్‌పై ముందుంచుతుంది, కాబట్టి
CORS సమస్య లేదు, పునరుద్ధరించాల్సిన సర్టిఫికెట్ లేదు. లైవ్‌కు వెళ్ళే ముందు డెమో క్లినిక్‌ను
లోడ్ చేసి చూడటానికి `SEED_ON_STARTUP=1` సెట్ చేయండి.

ఇమేజ్‌లు: [`dentalpin-backend`](https://github.com/dentalpin/dentalpin/pkgs/container/dentalpin-backend) ·
[`dentalpin-frontend`](https://github.com/dentalpin/dentalpin/pkgs/container/dentalpin-frontend)

## త్వరిత ప్రారంభం (డెవలప్‌మెంట్)

హాట్ రీలోడ్‌తో సోర్స్ నుండి బిల్డ్ చేస్తుంది:

```bash
# సేవలను ప్రారంభించండి
docker-compose up -d

# డెమో డేటాను లోడ్ చేయండి (డిఫాల్ట్‌గా ఇంగ్లీష్)
./scripts/seed-demo.sh

# లేదా స్పానిష్‌లో
./scripts/seed-demo.sh --lang es

# భారత GST డెమో క్లినిక్ (తమిళ UI, లేదా --country in తో ఇంగ్లీష్ UI)
./scripts/seed-demo.sh --lang ta

# హైదరాబాద్, తెలంగాణలో భారత GST డెమో క్లినిక్ (తెలుగు UI)
./scripts/seed-demo.sh --lang te
```

http://localhost:3000 తెరవండి

## ఫీచర్లు

### AI కోపైలట్
- **ఏజెంటిక్ సహాయకుడు** — నిజమైన ఆపరేషన్లను పిలిచి రోగులు, షెడ్యూల్, రీకాల్స్, అంచనాలు, చెల్లింపులు మరియు నివేదికలలో అనేక-దశల పనులను ప్రణాళిక చేసి అమలు చేసే సంభాషణ ఏజెంట్
- **RBAC సమానత్వం** — ప్రతి చర్య యూజర్ అనుమతులతో మళ్ళీ తనిఖీ చేయబడుతుంది; ఆ యూజర్ UI ద్వారా చేయగలిగినది మాత్రమే ఏజెంట్ చేయగలదు, వారి క్లినిక్‌కు పరిమితం
- **PHI రిడాక్షన్** — LLM కు చేరే ముందు రోగి గుర్తింపులు టోకెన్లుగా మార్చబడతాయి; ఉచిత-పాఠ్య క్లినికల్ డేటా క్లౌడ్ మార్గంలోకి వెళ్ళదు. డిఫాల్ట్‌గా ఆన్
- **నిర్ధారించిన మార్పులు** — డేటాను మార్చే చర్యలు సంభాషణ మధ్యలో యూజర్ స్పష్టమైన నిర్ధారణ కోసం ఆగుతాయి
- **పని ప్రక్రియలు & సారాంశం** — ఒక్క నొక్కుతో ప్లేబుక్‌లు (రోజువారీ సారాంశం, సందర్శనకు సిద్ధం చేయడం, ఖాళీని భర్తీ చేయడం) మరియు ఎంచుకుంటే ఉదయపు ఈమెయిల్ సారాంశం
- **బహుభాషా & వెండర్-స్వతంత్రం** — మీ UI భాషలోనే మాట్లాడుతుంది; LLM ప్రొవైడర్, మోడల్ మరియు క్లినిక్ వారీ టోకెన్ బడ్జెట్ కాన్ఫిగర్ చేయవచ్చు

### క్లినికల్ నిర్వహణ
- **రోగి రికార్డులు** — వ్యక్తిగత డేటా, సంప్రదింపు సమాచారం, వైద్య చరిత్ర మరియు గమనికలతో పూర్తి రోగి ప్రొఫైళ్లు
- **దంత చార్ట్ (ఓడోంటోగ్రామ్)** — ప్రతి దంతం/ఉపరితలానికి చికిత్స ట్రాకింగ్‌తో ఇంటరాక్టివ్ దంత రేఖాచిత్రం
- **అపాయింట్‌మెంట్ క్యాలెండర్** — లాగి వదిలే (drag & drop) సౌకర్యం, వైద్యుల కాలమ్‌లు, సమయ ఘర్షణ గుర్తింపుతో వారపు మరియు రోజువారీ వీక్షణలు
- **చికిత్సల క్యాటలాగ్** — కోడ్‌లు, ధరలు, పన్ను రకాలు మరియు వర్గాలతో అనుకూలీకరించగల క్యాటలాగ్

### ఆర్థిక నిర్వహణ
- **అంచనాలు** — చికిత్స అంచనాలు సృష్టించండి, ఆమోద ప్రక్రియను గమనించండి (డ్రాఫ్ట్ → పెండింగ్ → ఆమోదించబడింది/తిరస్కరించబడింది), రోగి సంతకం, PDF రూపొందింపు
- **ఇన్‌వాయిస్‌లు** — అంచనాల నుండి లేదా స్వతంత్రంగా ఇన్‌వాయిస్‌లు రూపొందించండి, స్వయంచాలక సంఖ్యాక్రమం, అనేక చెల్లింపు పద్ధతులు, PDF ఎగుమతి
- **చెల్లింపులు** — పాక్షిక చెల్లింపులు, చెల్లింపు చరిత్ర, బకాయి లెక్కింపు

### ప్రాక్టీస్ నిర్వహణ
- **పాత్ర-ఆధారిత యాక్సెస్ నియంత్రణ** — సూక్ష్మ అనుమతులతో ఐదు పాత్రలు (అడ్మిన్, దంత వైద్యుడు, హైజీనిస్ట్, సహాయకుడు, రిసెప్షనిస్ట్)
- **క్యాబినెట్/గది నిర్వహణ** — షెడ్యూళ్లు మరియు రంగులతో చికిత్స గదులను నిర్వచించండి
- **వైద్యుల నిర్వహణ** — నిర్దిష్ట దంత వైద్యులు/హైజీనిస్టులకు అపాయింట్‌మెంట్లు కేటాయించండి

### వినియోగదారు అనుభవం
- **దృశ్య ఎంపికలు** — ఇటీవలి రోగులు మరియు ప్రసిద్ధ చికిత్సలను చూపించే తెలివైన డ్రాప్‌డౌన్‌లు
- **పదకొండు భాషల ఇంటర్‌ఫేస్** — ఇంగ్లీష్, స్పానిష్, ఫ్రెంచ్, పోర్చుగీస్, తమిళం, తెలుగు, జర్మన్, హంగేరియన్, పోలిష్, ఇటాలియన్ మరియు అరబిక్ — కోర్ యాప్ మరియు ప్రతి మాడ్యూల్
- **డార్క్ మోడ్** — సిస్టమ్ సెట్టింగ్ ఆధారంగా థీమ్ మార్పు
- **రెస్పాన్సివ్ డిజైన్** — డెస్క్‌టాప్ మరియు టాబ్లెట్‌పై పని చేస్తుంది

### సాంకేతిక ఫీచర్లు
- **మాడ్యులర్ ఆర్కిటెక్చర్** — సులభమైన విస్తరణ కోసం ప్లగిన్-ఆధారిత వ్యవస్థ
- **ఈవెంట్ బస్** — నోటిఫికేషన్లు మరియు అనుసంధానాల కోసం మాడ్యూల్‌ల మధ్య సంప్రదింపు
- **REST API** — OpenAPI డాక్యుమెంటేషన్‌తో పూర్తి API
- **రియల్-టైమ్ నవీకరణలు** — ఆశావాద నవీకరణలతో రియాక్టివ్ UI

## భాషలు

ఇంటర్‌ఫేస్ **పదకొండు భాషలలో** అందుబాటులో ఉంది — English, Español, Français, Português,
தமிழ் (Tamil), తెలుగు (Telugu), Deutsch, Magyar, Polski, Italiano మరియు العربية (Arabic) — కోర్ యాప్ **మరియు
ప్రతి మాడ్యూల్ పొర**ను కవర్ చేస్తుంది. లొకేల్‌లు నిశ్శబ్దంగా వేరుపడకుండా CI ద్వారా అమలయ్యే కీ-సమానత్వ పరీక్ష ఉంది.
పోలిష్ దాని పూర్తి మూడు-రూపాల బహువచన నియమాలను వాడుతుంది.

రోగులకు పంపే సంప్రదింపులు (ఈమెయిల్ టెంప్లేట్లు, PDF లు) ప్రస్తుతం
**ఆరు భాషలలో** (es, en, fr, pt, ta, te) రూపొందుతాయి; ప్రతి క్లినిక్ సిబ్బంది UI భాషతో సంబంధం లేకుండా
తన సంప్రదింపుల భాషను ఎంచుకుంటుంది.

మీ భాష కావాలా? కొత్త భాషను జోడించడం కేవలం అనువాద సహకారం మాత్రమే — 
[i18n issues](https://github.com/dentalpin/dentalpin/issues?q=label%3Ai18n) చూడండి లేదా

## డెవలప్‌మెంట్

### ముందస్తు అవసరాలు

- Docker మరియు Docker Compose (డెవ్ స్టాక్‌కు 4GB RAM సరిపోతుంది; `Dockerfile.prod` నుండి
  ప్రొడక్షన్ ఫ్రంటెండ్ ఇమేజ్ బిల్డ్ చేయడానికి 6GB+ అవసరం — అక్కడి
  `NODE_OPTIONS` గమనిక చూడండి)
- Python 3.11+ (స్థానిక బ్యాకెండ్ డెవలప్‌మెంట్ కోసం)
- Node.js 18+ (స్థానిక ఫ్రంటెండ్ డెవలప్‌మెంట్ కోసం)

### స్థానికంగా నడపడం

```bash
# అన్ని సేవలను ప్రారంభించండి
docker-compose up

# లేదా బ్యాకెండ్‌ను విడిగా నడపండి
cd backend
pip install -e ".[dev]"
uvicorn app.main:app --reload

# లేదా ఫ్రంటెండ్‌ను విడిగా నడపండి
cd frontend
npm install
npm run dev
```

### డేటాబేస్ నిర్వహణ

```bash
# డేటాబేస్ రీసెట్ చేసి మైగ్రేషన్లు నడపండి
./scripts/reset-db.sh

# డెమో డేటా లోడ్ చేయండి (ఇంగ్లీష్ - డిఫాల్ట్)
./scripts/seed-demo.sh

# డెమో డేటా లోడ్ చేయండి (స్పానిష్)
./scripts/seed-demo.sh --lang es

# డెమో డేటా లోడ్ చేయండి (తెలుగు — హైదరాబాద్ క్లినిక్, భారత GST)
./scripts/seed-demo.sh --lang te

# పూర్తి సెటప్ (రీసెట్ + డేటా లోడ్ ఒకే కమాండ్‌లో)
./scripts/setup-demo.sh
```
